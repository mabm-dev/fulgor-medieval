## Pieza piloto: Castilla

Fuente vigente: `heroe_rodrigo_diaz_castilla.png`.

Rasgos observados: pelo oscuro ondulado, barba corta, rostro maduro, capa
granate recogida con broche redondo, cota de malla, armadura de cuero,
correajes, brazales y espada. El encuadre no define por completo piernas
ni construcción de espalda: cualquier ampliación requiere revisión.

Lámina derivada y prompt:
[Concept/CastillaRodrigoV01](../../Concept/CastillaRodrigoV01/README.md).

Escena Blender de preparación:
`ArtSource/Blender/Heroes/CastillaRodrigoV01/Rodrigo_referencias_v01.blend`.
Contiene imágenes de referencia y cámaras, todavía no una escultura del héroe.

## Conservación

Los doce PNG originales se mantienen sin retocar. Preparar derivados
optimizados dentro de Assets cuando se integren. El inventario del proyecto
registra aportación del propietario y auditoría comercial pendiente.
LegacyWeb se conserva como archivo histórico, no como fuente visual vigente.
