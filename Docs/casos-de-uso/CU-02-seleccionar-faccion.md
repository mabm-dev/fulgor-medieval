# CU-02: seleccionar facción y héroe

## Objetivo

Comparar identidades jugables antes de confirmar una campaña.

## Flujo principal

1. El jugador recorre los héroes disponibles.
2. Al enfocar o señalar uno aparece su nombre.
3. Al seleccionarlo se muestra la ficha de facción.
4. La ficha explica ventaja, orden, unidad, edificio y debilidad.
5. El jugador confirma la selección.

## Criterios de aceptación

- Ratón, teclado y control pueden recorrer las opciones.
- El efecto visual no oculta al personaje.
- Ninguna facción se describe solo mediante color o trasfondo.
- El líder elegido queda asociado al estado de campaña.
