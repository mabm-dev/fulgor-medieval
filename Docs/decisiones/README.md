# Registro de decisiones

Los ADR documentan decisiones difíciles de cambiar. No registran cada ajuste
visual ni sustituyen al historial Git.

| ADR | Estado | Decisión |
|---|---|---|
| [ADR-001](ADR-001-videojuego-react-typescript.md) | Sustituida | Aplicación de videojuego con React y TypeScript |
| [ADR-002](ADR-002-motor-determinista.md) | Aceptada | Motor de dominio determinista |
| [ADR-003](ADR-003-migracion-unity.md) | Aceptada | Migrar el videojuego a Unity |

Una decisión nueva debe incluir contexto, alternativas, elección y
consecuencias. Una decisión sustituida no se borra: se marca como tal y enlaza
a la que la reemplaza.
