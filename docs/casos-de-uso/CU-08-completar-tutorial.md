# CU-08: completar el tutorial

## Objetivo

Aprender el bucle principal mediante una campaña corta que puede reanudarse.

## Flujo principal

1. El jugador inicia la crónica tutorial.
2. Recibe un objetivo y su motivo.
3. Realiza una acción usando reglas normales.
4. El tutorial observa el evento de éxito.
5. Muestra la consecuencia y abre el siguiente objetivo.
6. El jugador completa una victoria reducida.

## Alternativas

- Pedir ayuda amplía la explicación.
- Saltar desactiva la guía sin invalidar la campaña.
- Reiniciar restaura la semilla y el estado inicial.

## Criterios de aceptación

- No depende de coordenadas visuales.
- Puede guardarse y continuar.
- Enseña economía, mapa, ejército, amenaza y diplomacia.
- Cada paso permite comprender la consecuencia de la acción.
