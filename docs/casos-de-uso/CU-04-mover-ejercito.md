# CU-04: mover un ejército

## Objetivo

Trasladar una formación estratégica respetando terreno, control y suministro.

## Flujo principal

1. El jugador selecciona un ejército propio.
2. El mapa muestra alcance y costes.
3. El jugador elige destino.
4. El juego calcula y previsualiza la ruta.
5. El jugador confirma la orden.
6. La fase de resolución mueve el ejército o genera un encuentro.

## Criterios de aceptación

- La ruta informa turnos, coste y riesgo.
- Terreno, caminos y zonas de control modifican el movimiento.
- No se revela información oculta al calcular.
- Un ejército sin suministro recibe consecuencias visibles.
