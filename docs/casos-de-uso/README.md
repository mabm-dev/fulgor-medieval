# Casos de uso

Los casos de uso describen el comportamiento observable del videojuego. No
deciden qué componente React, tabla o función concreta lo implementa.

## Plantilla

Cada caso contiene objetivo, actores, precondiciones, flujo principal,
alternativas, resultado y criterios de aceptación. Las reglas detalladas viven
en `docs/diseno/`; los cambios implementados se registran en `CHANGELOG.md`.
